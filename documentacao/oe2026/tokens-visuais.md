# Tokens visuais iniciais

Estes tokens preparam a futura interface. Não fazem parte do contrato, da origem dos dados nem de qualquer classificação orçamental.

| Token | Valor | Uso |
|---|---:|---|
| `surface.canvas` | `#FFFFFF` | Base branca da aplicação |
| `text.primary` | `#1A1A1A` | Texto principal e valores |
| `accent.danger` | `#B42318` | Erro, rejeição ou falha de validação |
| `accent.warning` | `#8A5D00` | Aviso, limitação ou estado pendente |
| `accent.success` | `#067647` | Validação concluída ou confirmação |

Os três acentos remetem para vermelho, amarelo e verde, mas não representam partido, ideologia, prioridade, mérito, categoria de despesa ou magnitude financeira. Cor nunca será o único sinal: cada estado deverá ter texto e, quando necessário, ícone ou padrão.

Os acentos foram escolhidos para contraste mínimo WCAG AA sobre branco: vermelho 6,57:1, amarelo 5,76:1 e verde 5,69:1. A futura interface deverá validar novamente contraste no contexto real e usar neutros/legendas para dados, não a paleta de estados.
